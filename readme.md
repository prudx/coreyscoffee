# Corey&apos;s Coffee

A monochrome React + Vite single-page concept for ordering Corey’s Coffee beans, capsules, and subscriptions.

## Getting started

Install dependencies (Node 18+ recommended):

```bash
npm install
```

## Running the development server

Start Vite and open the provided local URL to explore the mockup:

```bash
npm run dev
```

The command prints a localhost address (typically [http://localhost:5173](http://localhost:5173)) that you can open in your browser. Vite will hot-reload as you edit the source files in `src/`.

## Building for production

Generate an optimized production build with:

```bash
npm run build
```

Preview the built output locally with:

```bash
npm run preview
```
